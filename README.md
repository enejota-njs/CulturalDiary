# Cultural Diary

The **Cultural Diary** is an application developed to allow users to record, organize, and revisit their cultural experiences in a practical and intuitive way. This tool is designed to store information about **books read**, **movies watched**, and **TV series followed**, enabling users to keep personal track of cultural content over time.

## Features

- **Complete content registration**: Allows users to register books (with ISBN), movies, and series (with seasons), including details such as title, author or director, cast, release year, and genre.
- **Ratings and reviews**: Users can assign ratings and write critical comments about each book, movie, or series season, encouraging reflection on the content consumed.
- **Smart search system**: Users can search for entries by title, genre, author/director, release year, ISBN (for books), or actors (for movies and series).
- **Filtering and sorting**: Users can filter content by genre and release year and sort results by rating (from highest to lowest or vice versa).
- **Detailed view**: Upon selecting an item from the list, users can access a detailed view with additional information and associated reviews, keeping the data well-organized and easy to navigate.
- **Data persistence**: All information is saved persistently, allowing the user’s history to be accessed even after the application is closed.

## Graphical Interface

In addition to all these features, the project includes a user-friendly **graphical interface**, designed to provide a smooth and pleasant user experience. The interface facilitates navigation between different sections of the system and ensures accessibility even for users with limited technical experience.

## Programming Languages

- Java

## Technologies Used

- **JavaFX**: Used to build the graphical user interface (GUI), enabling dynamic and responsive screen transitions and layouts.
- **JSON**: Data about books, movies, and series is stored in **JSON** format for readability and structure.
- **Gson**: The **Gson** library is used for serializing and deserializing Java objects to and from JSON, ensuring smooth data persistence and retrieval.

## Final Considerations

This application was developed as part of an academic project for the **State University of Feira de Santana (UEFS)**, in the **Computer Engineering** program. Its main purpose was to apply and consolidate knowledge acquired in areas such as object-oriented programming, data manipulation, user interface development, and file persistence.

Throughout the project, various technologies were explored, including Java, JavaFX, JSON, and the Gson library — providing hands-on experience with real-world tools and practices used in software development.

Beyond meeting the academic goals, the **Cultural Diary** also encourages users to reflect on their cultural journey, organizing personal experiences in a meaningful and accessible way.
